# Reserve asset library

Everything under `assets/reserve/` is kept in the source repository for reference and future work. The build never copies this tree to the deployed site.

- `portraits/` holds earlier portrait experiments and the chibi master.
- `reactions/` holds the portrait and chibi expression sets, including the siren loops.
- `studies/neck/` holds the cable study sheet and its four labeled crops.

The current website identity assets are in the sibling `assets/published/` tree. The builder copies only its explicit allowlist into `dist/assets/`.
