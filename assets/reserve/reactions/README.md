# P-06 reaction references

These portrait and chibi expression variants are reference assets; they do not replace the main portrait. `portrait/` suits serious or technical reactions, while `chibi/` suits lighter moments.

## Portrait reactions

The portrait expressions were generated from the current profile portrait. `urgent-focus-sirens.gif` is a four-frame loop alternating the illuminated red and blue sirens.

- `portrait/pride.png`
- `portrait/satisfaction.png`
- `portrait/embarrassment.png`
- `portrait/dissatisfaction.png`
- `portrait/begrudged-amusement.png` — the first contempt attempt, read as trying not to smile or laugh.
- `portrait/urgent-focus.png` — the instant P-06 realizes something is about to go wrong and has little time to act.
- `portrait/urgent-focus-sirens.gif`
